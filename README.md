# Hussein's Portfolio

## About the Project
A responsive personal portfolio website built from scratch using HTML, CSS, and JavaScript without frameworks or UI libraries.

## Features
- **About Me:** Personal introduction and profile photo.
- **Skills:** Grid displaying technical skills.
- **Projects:** Showcase of Projects 00–03.
- **Hobbies:** Personal interests.
- **Contact Form:** Form for entering name, email, and message.
- **Theme Switcher:** Button to toggle between light and dark themes.
## Technologies Used
- HTML5
- CSS3 (Flexbox and Media Queries)
- JavaScript (DOM Manipulation and Event Handling)
